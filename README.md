# 🏋️ Banco de Dados de Academia

## 📌 Sobre o projeto

Este projeto foi desenvolvido durante as aulas para praticar SQL e criar um banco de dados para gerenciar informações de uma academia.

## 🗂️ Tabelas

- **PLANOS:** armazena os planos e seus valores mensais.
- **ALUNOS:** armazena os dados dos alunos.
- **PROFESSORES:** registra os professores.
- **AULAS:** registra as aulas disponíveis.
- **AGENDAMENTOS:** relaciona alunos às aulas agendadas.

## 💻 Conceitos praticados

- Criação de tabelas com `CREATE TABLE`
- Chaves primárias com `PRIMARY KEY`
- Relacionamentos com `FOREIGN KEY`
- Inserção de dados com `INSERT INTO`
- Consultas com `SELECT`
- Funções de agregação, como `SUM` e `AVG`
- Relacionamentos entre tabelas com `INNER JOIN`

## 🛠️ Tecnologias

- SQL
- SQLite, se este foi o banco de dados utilizado na aula

## 📁 Arquivo principal

- `academia.sql`: contém a criação das tabelas, os dados de exemplo e as consultas SQL.
